# Химия: органика и неорганика — образовательный портал

Образовательный веб-портал по органической и неорганической химии (10–11 классы и СПО) с 3D-визуализацией молекул и атомов (Three.js), интерактивными заданиями, таблицами, справочником, конструктором реакций и личным кабинетом.

Приложение поддерживает **два режима работы без изменения кода**:
1. **Серверный режим (Node.js + Express)** — при запуске на собственном сервере, VPS, Docker, Render, Railway или Timeweb используется встроенный backend `/api/*` с серверным хранением пользователей и прогресса.
2. **Автономный статический режим (GitHub Pages / Netlify / Vercel / Nginx)** — если бэкенд `/api/health` недоступен, приложение автоматически переключается на локальный браузерный движок с хэшированием паролей через Web Crypto (`PBKDF2`) и сохранением прогресса, заданий и избранного в браузере.

---

## Вариант 1: Выкладка на GitHub Pages (бесплатно и автоматически)

В репозитории уже настроен рабочий процесс `.github/workflows/deploy-pages.yml` и относительные пути сборки (`base: './'`), поэтому сайт сразу работает по адресу вида `https://<ваш-логин>.github.io/<название-репозитория>/`.

1. Загрузите проект в репозиторий GitHub (ветка `main` или `master`).
2. Откройте в репозитории **Settings → Pages**.
3. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
4. После следующего `git push` (или ручного запуска в **Actions → Deploy to GitHub Pages → Run workflow**) сайт автоматически соберётся и опубликуется.

---

## Вариант 2: Выкладка на другой сервер (VPS / Render / Railway / Timeweb)

Требуется **Node.js 22+** (поддержка запуска `node server.ts` без дополнительной компиляции сервера).

```bash
npm ci
npm run build
npm start
```

По умолчанию сервер слушает порт `3000` (можно изменить переменной `PORT`).
База пользователей и прогресса хранится в `DATA_DIR` (по умолчанию `./data/chem-db.json`).

Если на сервере установлен Node.js 20, используйте:

```bash
npm ci
npm run build
npm run start:tsx
```

## Вариант 3: Запуск через Docker

```bash
docker build -t chem-portal .
docker run -d \
  --name chem-portal \
  -p 3000:3000 \
  -v chem_portal_data:/app/data \
  chem-portal
```

Том `chem_portal_data` сохраняет учётные записи и учебный прогресс при обновлении контейнера.

---

## Вариант 4: Статический хостинг (Nginx / Apache / Timeweb Static / Netlify / Vercel)

1. Выполните сборку:
   ```bash
   npm ci
   npm run build
   ```
2. Загрузите содержимое папки `dist/` в корневую папку сайта (или в подпапку — пути относительные).
3. Все разделы, 3D-модели, таблицы, задания, конструктор реакций и личный кабинет будут работать полностью автономно.

---

## Вариант 5: Фронтенд на GitHub Pages + API на своём сервере

Если вы хотите, чтобы сайт открывался с GitHub Pages, но данные пользователей сохранялись на вашем внешнем сервере:

1. На внешнем сервере задайте переменную окружения:
   ```bash
   CORS_ORIGIN="https://<ваш-логин>.github.io"
   ```
2. В репозитории GitHub перейдите в **Settings → Secrets and variables → Actions → Variables** и добавьте переменную:
   - `VITE_API_BASE_URL` = `https://api.your-domain.ru` (без слэша в конце).
3. Перезапустите деплой GitHub Pages.
